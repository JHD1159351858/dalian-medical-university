# 医院问诊智能体

面向临床问诊训练的三维医院场景。患者王旭行走到接诊点，学生以“接诊医生”身份听取主诉并进行文字问诊；系统不提供评分、诊断结论、处方或治疗方案。

## 运行

需要 Node.js `>=22.12.0` 和 npm。在 `hospital-agent` 目录执行：

```bash
npm install
npm run dev
```

默认打开 `http://localhost:5173`。若该端口已被占用，Vite 会自动选择可用端口；本次运行使用 `http://localhost:5174`，以终端实际输出的地址为准。开发时 API 服务运行在 `3001`，Vite 将 `/api` 代理到 `http://127.0.0.1:3001`。

生产构建与启动：

```bash
npm run build
npm start
```

打开 `http://localhost:3000`。请通过 HTTP 服务访问，不能双击 `index.html` 打开。

## AI 服务配置

复制 `.env.example` 为 `.env`，再填写：

```dotenv
OPENAPI_BASE_URL=https://api.coze.cn
OPENAPI_TOKEN=your-coze-api-token
PATIENT_BOT_ID=7687864464020619300
PATIENT_VOICE_ID=your-coze-voice-id
PORT=3001
```

问诊调用已发布的 Coze 智能体，并通过 `custom_variables.case_data` 传入服务端的 `server/case.json`。密钥仅保留在服务端 `.env` 中；不要使用 `VITE_` 环境变量，也不要将密钥写入前端代码。未配置智能体 ID 或密钥时，界面会显示服务不可用。

问诊文字通过 SSE 连续显示，语音通过 `/api/speech-stream` 接入扣子双向流式语音合成。后端使用 `OPENAPI_TOKEN` 鉴权，令牌需具备 `createSpeech` 权限；浏览器顺序播放返回的 PCM 音频，不等待整段合成完成。停止朗读或静音只停止语音，文字仍继续输出；返回场景或结束接诊会取消当前请求和播放。固定主诉及预缓存的体格检查语音继续使用原有 `/api/tts`。

## 使用流程

1. 首页展示医院小镇及街道上的行人、车辆。点击“开始实训”卸载小镇并进入原医院，患者自动穿过入口前往候诊区；重播或开始下一轮时，仍通过“进入医院”开始。
2. 使用 `W`、`A`、`S`、`D` 或方向键以相机视角移动医生。触摸设备可使用“医生移动摇杆”。医生巡行速度为 1.1 米/秒，患者为 0.85 米/秒，骨骼步频随实际移动速度同步。
3. 靠近患者至 1.2 米内、面向患者且中间没有遮挡时，按 `F` 或点击“接诊”。患者会说“医生我身体不舒服”，随后点击“开始诊断”。
4. 诊断页左侧为患者，右侧为学生医生；在“向患者提问”输入问题并发送。可切换语音朗读或停止朗读。
5. “返回场景”会保留人物位置和聊天记录。再次靠近时按 `F` 或点击“继续接诊”，再点击“继续诊断”，不会重复主诉。
6. 完成问诊后点击“结束接诊”。患者离开医院并完成门禁通行后，可点击“开始下一轮”；“重置训练”会立即开始新会话。

入口双开门支持主动互动：医生靠近门中央 2.1 米内并面向门时，按 `F` 开门／关门；触屏显示同名按钮。手动打开后保持开启，需再次操作关闭。患者进出仍会自动开门；患者正在通过或任何角色处于门扇扫掠区时禁止关门，退开后再操作。

## 验证与边界

```bash
npm test
npm run test:e2e
```

端到端测试会启动 `4173` 和 `3001` 服务，需要已安装的 Chrome，或设置 `CHROME_PATH`。测试覆盖键盘、触摸摇杆、门禁通行、问诊返回与 WebGL 画布尺寸，但不替代真机的触摸延迟、WebGL 性能或无障碍辅助技术验证。实际模型回复依赖 Coze 服务和令牌权限。

本次验证结果、测试条件及剩余验收项见 [验证记录](verification/REPORT.md)；资源来源和动画对应关系见 [三维资源说明](ASSETS.md)。

## 排错

- 模型资源 404：确认从 `hospital-agent` 的 HTTP 服务启动，并保留开发目录的 `public/models` 或构建目录的 `dist/models`。病例仅保存在服务端 `server/case.json`，不要复制到公开目录。
- 场景黑屏或无法加载：检查浏览器 WebGL 与硬件加速是否启用。
- 人物报“缺少骨骼动画”：检查运行时 `patient.glb`、`doctor.glb` 是否含 `Idle`、`Walk`、`Talk` 三个片段。
- 聊天空白或连接失败：检查 `.env` 的 `OPENAPI_TOKEN`、`PATIENT_BOT_ID`、服务地址与网络连通性。
- 没有中文语音：设备可能未安装中文语音；文字回答仍可正常显示。
