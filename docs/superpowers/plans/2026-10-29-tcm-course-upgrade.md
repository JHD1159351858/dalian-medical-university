# 中医课程修改实施计划

用户已在本聊天确认按三份文档的分析开发，使用独立分支，后续再合入主分支。

**目标：** 患者按问披露资料；四诊提供可操作的观察和问答；舌象照片用于独立学习；脉诊提供规范布指演示；处置提交后返回可追溯的评价。

**隔离：** 原项目未有 Git 历史，已建立本地 main 基线。所有功能修改位于 feature/tcm-course-upgrade 工作树，完成后提交，暂不合并。

**边界：** 不改登录、经营、持久化或数据库。保持现有整体视觉和六模块导航。不把学习图库随机结果当成本病例所见。不新增未经教师确认的病例舌象、脉象、处方或评分标准。处置标准未审核时返回待教师确认，不能自动通过。无线上评估配置时明确标识，不伪装真实 AI 结果。

## 1. 病例与患者回答

- [x] 更新开场为“医生，我左上腹痛，您帮我看看。”，病程 2—3 天、油腻食物后加重、胀痛及文档其余症状按问披露。
- [x] 新增 server/patientInterview.mjs，接口 patientInterviewReply(messages, caseData): string | null。已确认问题返回确定回答；无匹配时返回 null，由既有患者聊天处理。禁止索取全部病历绕过披露规则。
- [x] 更新 server/case.json 与病例摘要，保留无关既有资料，但去除冲突的开场泄露。原呼吸困难信息作为旧病例记录，不在开场主动透露。
- [x] 测试：不问时间/饮食不披露；同义追问、多问题、诱导相反回答、重复提问和病例摘要一致性。

## 2. 四诊观察与舌象学习

- [x] 保留现有三维患者、页签和聊天记录；增加上下文对应的提问快捷入口。
- [x] 从用户 DOCX 提取 12 张原图，保存来源、13 项形态说明、同图多标签关系和带文字标注的学习限制。
- [x] 本病例舌象待教师确认；独立学习区可随机出题，同一题观察期间图片不变，先作答再显示解释，明确学习结果不写入病例记录。
- [x] 展示缺少的望诊照片、闻诊样本和口臭病例结论为待补充，提供已有患者语音播放，不模拟成教师样本。
- [x] 复用独立教学动作组件：TongueTeaching / PulseTeaching，分别由动画任务负责。
- [x] 测试：素材数量与图片存在、标注图不出考核题、随机题稳定、病例与学习区不混用。

## 3. 教学动作

- [x] 新增 src/clinical/ExaminationTeaching.tsx 与独立样式，导出 TongueTeaching()、PulseTeaching()，无需外部属性。
- [x] 舌诊显示患者示意形象的张口、伸舌、保持观察过程；明确为教学示意，不宣称现有患者 GLB 已有新动作。
- [x] 脉诊显示患者前臂伸出、掌心向上、中指定关、食指定位寸、无名指定位尺，镜头聚焦手腕与三指，文字与动作同步。
- [x] 支持播放、暂停、重播和逐步查看，遵循减少动态效果偏好。动作不输出未经确认的病例脉象。
- [x] 测试：步骤顺序、控制状态、重新播放和减少动态效果下可逐步完成。

## 4. 处置评价

- [x] 新增 server/treatmentEvaluation.mjs 与 server/treatment-rubric.json，标准包含审核状态、依据与必需/禁止/可接受条目；当前病例未提供教师标准，默认审核状态为 false。
- [x] 新增 POST /api/treatment-evaluation，校验提交的诊断、处置、用药，拒绝超大与异常输入；评价输出区分待确认、通过、需要修改。
- [x] 固定规则给出对应条目、学生原文、遗漏/错误原因与依据；没有审核标准不能通过。可选 EVALUATION_BOT_ID 接入 Coze 核对引用，逐字验证学生原文与已有标准，拒绝自由结论，模型不能改写未审核状态或覆盖确定规则。
- [x] 前端新增评价服务与结果区。提交期间禁止重复操作，修改方案后作废旧评价，失败不显示通过；完成训练需先提交，保留明确的“待教师确认后结束训练”路径。
- [x] 测试：未审核标准、正确/错误/遗漏规则、同义词、否定表达、伪造通过、服务错误与结果失效。
