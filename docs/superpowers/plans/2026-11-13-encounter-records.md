# 接诊记录实施计划

**目标**：点击医院前台电脑，查看当前学生历次接诊患者及完整训练记录；记录保存到 Supabase，后续超星登录负责兑换 Supabase Auth 会话。

**范围**：当前王旭病例；同一病例每轮独立归档；不修改小镇首页，不增加教师端、评分规则或超星认证中心。

1. 新建云端表及 Next/Express 记录接口：按服务端核验的 Auth 用户隔离。验证：未登录拒绝、跨用户拒绝、同轮更新不重复。
2. 新建客户端会话适配和串行保存：自动保存草稿、每次提交与结束状态；切换账号清空上一账号界面。验证：失败可重试、旧快照不能覆盖新快照。
3. 连接问诊、检查、四诊、诊断、处置记录：切换模块保留体检，保留病例舌诊/脉诊及处置历次提交。独立舌象学习仍不计入患者病例。
4. 在电脑位置增加“接诊记录”按钮，显示列表、分页和只读详情；弹窗打开时暂停医生移动。验证：实际点击、未配置/未登录/空状态和详情展示。
5. 完成针对性测试、类型检查、构建及本地浏览器验证，交付数据库迁移和登录接入指南。

**验收边界**：当前环境未提供 Supabase 配置、学生登录；只能验证接口隔离与模拟上游的读写，真实云存档和跨设备登录需在配置及超星桥接完成后验收。界面必须明确区分“尚未保存”“保存中”“已保存”“失败”，不得把模拟数据或本地内存称为云记录。
