# 小镇实训首页实施计划

目标：采用用户指定设计，小镇作为全屏首页背景，少量行人和车辆沿街道循环移动，中央“开始实训”一次点击进入原有小医院接诊。

设计：沿用现有医疗蓝、中文宋体标题与无衬线正文。小镇是主要视觉，中央简洁标题和按钮，不增加功能卡片。首页与问诊各自拥有独立场景；首页不运行碰撞和角色导航。点击按钮卸载并释放小镇 GPU 资源后加载原 App，自动开始患者入院。原始 blend 不保存、不覆盖，原医院与角色 GLB 保持不变。

实施与验证：
1. 新增 tests 的浏览器用例，检查首页先显示、无医院模型下载、街景物体随时间移动、点击后小镇卸载且旧场景进入 walking/waiting。先运行确认缺少首页而失败。
2. scripts/prepare_town.py 将评估后的静态几何按材质合并，单独导出汽车；保留材质与场景外观，不导出相机灯光。验证面数、文件大小及绘制数。
3. src/home 新增首页、场景与街道动效；main.tsx 切换入口，App.tsx 增加首次自动开始参数。限制修改至首页入口，接诊逻辑不重构。
4. 适配现有 E2E 进入入口；运行生产构建、定向首页与接诊回归，桌面和手机视口截图检查，记录最终性能。真机手机不在本次测试范围。

资源策略：静态物件合并；行人低面几何、少量材质共享；车辆使用原模型提取。动画仅作环境展示，不实现交通 AI。背景资源失败仍允许开始实训，减少动态效果偏好时停止环境运动。仅挂载一个三维场景，不把小镇加入训练碰撞树。
