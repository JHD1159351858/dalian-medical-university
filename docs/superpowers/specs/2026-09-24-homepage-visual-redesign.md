# 首页视觉整改设计

## 目标
保留首页现有 3D 小镇和“开始实训”进入医院流程，在 3D 画面下使用 `首页空白背景图.png` 作为全屏底图，并叠加设计图中的品牌、标题、卖点、入口和页脚信息。

## 视觉结构
- 页面根容器使用全屏静态背景图，覆盖视口并保持裁切比例。
- 3D 小镇继续由 `TownBackground` 渲染，位于背景图之上；使用透明画布并隐藏模型自带的外部灰色底板，让小镇与设计图的浅蓝医疗背景融合。
- 顶部左侧显示大连医科大学品牌、临床问诊实训副标题；右侧显示教学模拟环境。
- 左侧显示英文眉题、两行中文主标题和副说明；下方显示临床思维训练、典型案例库、能力评估反馈三项卖点。
- 底部中央保留白色半透明入口卡片和“开始实训”按钮；点击行为不变。
- 底部左右显示医院小镇/临床情境模拟与准备提示。

## 交互与兼容
- 不改变 `startTraining`、资源预加载、3D 小镇加载状态和进入医院过渡。
- 3D 小镇加载失败时仍可点击开始实训，与当前行为一致。
- 小屏幕下隐藏非必要卖点或压缩排版，按钮保持可见和可点击。

## 验证
- 首页截图检查背景、文字层级、按钮和 3D 小镇同时可见。
- 现有首页 E2E 测试继续验证 3D 小镇动画和点击后进入医院。
