## 一、问诊（20 分）

患者开场固定为：

```text
大夫，我肚子左上边这块儿疼。
```


在问诊输入框依次提出下面的问题。右列是核对患者回答的要点，不要将患者答复当作医生提问输入。未确认资料仍应保留待确认。

| 序号 | 推荐医生提问 | 患者答复要点 |
| ---: | --- | --- |
| 1 | 哪里疼？ | 我左上腹痛。 |
| 2 | 腹痛多久了？ | 疼了两三天了。 |
| 3 | 疼痛是什么性质？ | 主要是胀痛。 |
| 4 | 进食后腹痛会加重吗？吃油腻食物后呢？ | 进食后腹痛会加重，吃油腻的食物后更明显。 |
| 5 | 按压会加重吗？ | 按压后腹痛会加重。 |
| 6 | 疼痛向其他地方放射吗？有没有腹胀？ | 疼痛没有向其他地方放射。有腹胀。 |
| 7 | 怕冷还是怕热？有没有发热？出汗多吗？ | 我怕热，没有畏寒、恶寒，也没有发热。比较容易出汗。 |
| 8 | 平时胃口怎么样？这两天能进食吗？ | 平时饮食还可以，这两天不能进食。 |
| 9 | 口干口渴吗？ | 口干，也觉得口渴。 |
| 10 | 大便怎么样，多久没排便？ | 大便困难，已经三天没有排大便了。 |
| 11 | 睡眠怎么样？ | 睡眠还可以。 |
| 12 | 有恶心、呕吐、腹泻、便血吗？ | 没有恶心。没有呕吐。没有腹泻。没有便血。 |
| 13 | 有胸闷、胸痛、咳嗽、咳痰吗？ | 没有胸闷。没有胸痛。没有咳嗽，也没有咳痰。 |
| 14 | 小便情况如何？ | 本病例小便情况待教师确认。 |
| 15 | 呼吸气短等情况如何？ | 本病例当前呼吸表现待教师确认。 |

## 二、体格检查（15 分）

先在“开具检查”中勾选以下 11 项并确认开单；可通过“查看电脑”逐项核对病例报告。选择各项，将下面原文填入该项记录，再点击“提交本项记录”。已经提交过的项目修改后需要重新提交。

### 1. 基本生命体征


```text
体温 37.5℃；脉搏 118 次/分；呼吸 32 次/分；血压 149/92 mmHg。
```


### 2. 锁骨上淋巴结


```text
双侧锁骨上未触及淋巴结肿大。
```


### 3. 皮肤及巩膜


```text
全身皮肤无黄染，皮肤散在大片白色色素沉着，无肝掌、蜘蛛痣。巩膜无黄染。
```


### 4. 营养状态


```text
中等，体型肥胖，急性面容，神志清楚。
```


### 5. 呼吸


```text
胸部无畸形，呼吸运动正常，肋间隙无增宽，呼吸频率增快；双肺呼吸音粗，未闻及明显干湿啰音。
```


### 6. 心律


```text
心率 118 次/分，律齐，各瓣膜区未闻及异常杂音，无心包摩擦感。
```


### 7. 神经系统


```text
肌力、肌张力正常。
```


### 8. 下肢


```text
双下肢无水肿，无静脉显露。
```


### 9. 腹部视触诊


```text
全腹膨隆，无胃肠型及蠕动波，腹肌略紧张，左上腹压痛明显，无反跳痛，肝脾肋下未及，Murphy 征阴性。
```


### 10. 腹部叩诊


```text
腹部叩诊呈鼓音，肝肾区无叩痛，无移动性浊音。
```


### 11. 肠鸣音


```text
肠鸣音减弱，2 次/分。
```


腹部触诊练习采用左上腹压痛、无反跳痛的病例结果。“阳性反跳痛示例”是独立教学演示，不要把演示结果写成本病例阳性发现。

## 三、中医四诊（15 分）

在望、闻、问、切及四诊总结的对应记录区填写。点击“查看望诊资料”后，观察人物图谱和舌象，舌象识图选“薄白苔”。脉诊先定位并轻取、深取，脉象选择“沉、滑、数”后提交判断。

### 望诊


```text
面颊及颈侧可见散在浅白色斑片，皮肤、巩膜无黄染。舌质淡红，苔薄白。
```


### 闻诊


```text
当前仅提供合成语声。语声特征、异常气味和当前呼吸表现均待教师确认，未提供可作阳性结论的真实记录。
```


### 问诊


```text
怕热，容易出汗；平时饮食尚可，近两天不能进食；口干口渴；大便困难，3日未排大便；睡眠尚可。无畏寒、恶寒、发热，否认恶心、呕吐、腹泻、便血、胸闷、胸痛、咳嗽、咳痰。小便情况待确认。
```


### 切诊


```text
脉沉、滑、数。左上腹压痛明显，无反跳痛。
```


### 四诊总结


```text
当前训练四诊所见为左上腹痛、怕热汗多口渴、便秘、面颊及颈侧散在浅白色斑片、舌质淡红苔薄白及沉滑数脉。原病例中医诊断为脾心痛、湿热毒蕴，病名证型沿用原记录，不以薄白苔单独推导该证型；小便及真实闻诊资料待确认。
```

## 已变更症状与资料边界

- 开场只说身体不舒服。腹痛部位、病程及与饮食、按压的关系，在医生询问对应主题后才披露。

- 最新问诊采用左上腹胀痛 2–3 天、怕热多汗、口干口渴、进食后及油腻食物后加重、三日未排便等事实；旧材料中的午后发热、偶有恶心、胸闷等冲突描述不恢复为当前阳性事实。

- 小便情况、异常气味、语声洪亮或低沉、当前主观呼吸表现等未确认项目保留待确认；不能以旧版诊断、合成声音或 AI 示意图推断这些结论。体检报告中已给出的呼吸频率和听诊结果仍按原报告记录。

- 原病例体检记载散在白色皮肤斑片，皮肤、巩膜无黄染。本版图谱在面颊和颈侧呈现斑片，望诊记录可用“浅白色斑片”“白斑”“色素减退斑”等词描述。

- 本版舌象为用户修订的舌质淡红、苔薄白，固定选择tongue-7；旧材料舌红苔黄燥腻已不作为当前舌象标准。脉象仍按原病例沉滑数记录。独立舌象学习中的随机条目不写入本病例。

- 原病例诊断记录可引用急性重症胰腺炎、急性呼吸窘迫综合征（轻度）、急性肾功能不全及脾心痛、湿热毒蕴；标明资料来源，不能因此编造患者当前呼吸困难、尿少或其他未确认病情。

- 该分数表示本病例资料复现程度。它不替代教师审阅，不代表通用诊疗正确性，也不是现实患者用药依据。
