# 新增五例门诊实训参考答案

本册用于林悦、陈阳、周宁、赵航、孙兰五个虚构教学病例，病例数值和报告为本轮教学设定，供教师审定。各例使用与[王旭病例](./王旭案例标准答案.md)相同的 11 项体格检查、7 项辅助检查目录和六个评分环节。

按各例的医生问句采集病史，将所见填入对应表单。辅助检查表中的“评分依据”列出本例需要记录的项目；其他项目按需开具，系统返回该患者的模拟报告，留空可得满分。处置按临床需要分行填写，药物剂量留待教师材料补充。各例的中医记录仅对应这名模拟患者。

## 林悦（女，28 岁）

**就诊线索**　右上腹阵发作痛。

**患者开场**　“医生，我右边肋骨底下疼得厉害。”

### 一、问诊（20 分）

| 医生提问 | 模拟患者的回答 |

### 五、诊断（20 分）

**西医主要诊断**　胆绞痛。油腻餐后右上腹痛，腹部超声提示胆囊结石。

**西医次要诊断**　未确立次要诊断。无发热及黄疸，Murphy征阴性，目前缺乏急性胆囊炎的证据。

**中医诊断**　胁痛。右胁胀痛牵及肩背，遇油腻发作，舌质淡红、苔薄白，脉弦。

**诊断总结**　胆囊结石伴胆绞痛。右上腹痛时有肩背牵扯感，超声见胆囊结石，未见胆管扩张。

### 六、处置（20 分）

1. 评估疼痛和生命体征，复查腹部压痛，观察发热、黄疸及持续腹痛。
2. 评估肾功能、胃肠道风险及过敏史后给予适宜镇痛，并复评疼痛变化。
3. 转肝胆外科，评估择期腹腔镜胆囊切除。
4. 等候处理期间避开诱发症状的高脂餐；出现持续腹痛、发热或黄疸及时急诊。

本例参考资料　[NICE 胆石病指南](https://www.nice.org.uk/guidance/cg188/resources/gallstone-disease-diagnosis-and-management-pdf-35109819418309)。

### 五、诊断（20 分）

**西医主要诊断**　急性阑尾炎。转移性右下腹痛，右下腹压痛伴局限性反跳痛，超声见阑尾增粗且不可压缩。

**西医次要诊断**　未确立次要诊断。局限性腹膜刺激征属于本次腹部体征，超声未见局限性脓肿。

**中医诊断**　肠痈。腹痛转至右下腹并固定，走动加重，舌质稍红、苔薄黄，脉滑数。

**诊断总结**　急性阑尾炎。右下腹局限性压痛，阑尾超声异常且白细胞和中性粒细胞升高，需要急诊外科评估。

### 六、处置（20 分）

1. 立即急诊普外科会诊，评估阑尾切除及手术时机。
2. 暂禁食，建立静脉通路；根据容量状态补液，按需镇痛止吐。
3. 连续复查生命体征和腹部体征，观察疼痛扩展或腹膜刺激征加重。
4. 由外科按分型、过敏史及本院方案评估并给予围术期抗菌药物。

本例参考资料　[英国 NHS 急性阑尾炎](https://www.nhs.uk/conditions/appendicitis/)；[WSES 急性阑尾炎指南（2025版）](https://doi.org/10.1001/jamasurg.2025.6218)。
